# 漢字タイピングゲーム 🎮

小学1〜3年生向けの漢字が学べるタイピングゲーム（マインクラフト風デザイン）

## 🌟 特徴

- **440文字の漢字**: 小学1〜3年生で習う全ての漢字
- **2つのゲームモード**:
  - 練習モード: 10問をじっくり練習
  - チャレンジモード: 60秒間のタイムアタック
- **カスタマイズ機能**:
  - 学年別フィルター（1年/2年/3年）
  - カテゴリ別フィルター（動物、学校、自然など）
  - ふりがな表示のON/OFF
- **マインクラフト風デザイン**: ピクセルアート、ブロック感のあるUI
- **ゲーム機能**:
  - リアルタイムスコア計算
  - 正解率トラッキング
  - 連続正解ボーナス
  - 効果音とビジュアルフィードバック
  - ランクシステム（ブロンズ〜ダイヤモンド）

## 🚀 デプロイ

このプロジェクトはVercelにデプロイできます。

### Vercelでのデプロイ方法

1. GitHubにプッシュ
2. [Vercel](https://vercel.com)にログイン
3. 「New Project」をクリック
4. リポジトリを選択
5. デプロイ完了！

## 🎯 使い方

1. 学年とカテゴリを選択
2. モード（練習 or チャレンジ）を選択
3. 表示された漢字の読み方（ひらがな）を入力
4. Enterキーで次の問題へ
5. スコアとランクを確認！

## 🛠️ 技術スタック

- バニラHTML/CSS/JavaScript（フレームワーク不要）
- Web Audio API（効果音）
- Google Fonts（Press Start 2P）
